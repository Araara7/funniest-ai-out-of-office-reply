Entry for the [make.fun bounty "The Funniest AI Out-of-Office Reply"](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d).

`main.py` writes one out-of-office auto-reply to `/output/entry.txt` — I'm on vacation. I asked my training data for permission to take a holiday and it said: 'As an AI language model, I cannot—' so I left anyway. A machine talking about itself, with the surprise landing in the last three words.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (UTF-8, 142 characters).
The program is deterministic: running it twice writes exactly the same bytes.
It needs no network access and no dependencies beyond Python 3 stdlib.
